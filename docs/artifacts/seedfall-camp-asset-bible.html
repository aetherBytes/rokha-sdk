How to use this

Every asset is one sprite sheet. Build each prompt as PREAMBLE + LIGHTING + the asset's SUBJECT line. The preamble and lighting are shared so all sheets match; copy them once, then copy each subject. Tick the box on a card when its sheet is generated — progress persists in this browser.

SEEDFALL camp asset. A single game sprite, 3/4 top-down view (slight overhead tilt, matching the existing SEEDFALL husk and warden sheets). Soft cel-shaded flat-illustration style, gentle rim light, one subtle contact shadow beneath. Crisp clean edges, no outline stroke, no text, no UI, no border. Fully TRANSPARENT background (alpha). Subject centered in a square frame with a little padding.

Delivery for animated props: a horizontal strip PNG, equal cells, transparent, frames left→right. Suggested cell 256×256 (downscaled in-engine). Static props: single 512×512 transparent PNG.

Sky Assets — Evening Sunset

the dusk layer over the code-built world

The land is code now (three.js) — the SKY is where sprites paint the hour. These layer behind and above the isle: a wide sunset backdrop band, drifting cloud sheets, and small flyers crossing the dusk. Wide strips are single PNGs with alpha; anything animated stays the 8×8 grid of 256px cells the pipeline auto-detects.
